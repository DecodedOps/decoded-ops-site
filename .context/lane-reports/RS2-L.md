## Chips styling observation (reproduced as the mockup renders)

The mockups use `<nav class="chips">` with anchor children, but the `.chips` pill styling in the
shared sheets (`d17-locations.css` / `locations-live.css`) targets `li` children only. I reproduced
the mockup's DOM exactly (`nav` + `next/link` anchors), so the chips render the same way the mockup
renders them. If the pills were intended, the fix is `.chips li, .chips a` in a shared sheet — a
forbidden file here.
